# Шифрование: отдельная реализация без внедрения

Модуль `infrastructure/encryption.py` не подключён к GUI, демону, хранилищу
или репозиториям. Существующие данные и их формат не меняются.

Реализован AES-256-GCM из библиотеки cryptography: шифрование с проверкой
целостности, случайный 12-байтовый nonce для каждой операции и ключ из 32 байт.
Формат: `CAENC`, версия `01`, nonce, шифротекст с 16-байтовым тегом.
Заголовок и внешний контекст аутентифицируются. Контекст можно задавать как
тип объекта, ID записи и имя поля, чтобы обнаруживать перенос шифротекста
между записями. Контекст не шифруется и не должен содержать секреты.

```python
from certificate_analyzer.infrastructure.encryption import DataCipher

key = DataCipher.generate_key()  # Секрет: не писать в журнал или рядом с данными.
cipher = DataCipher(key)
encrypted = cipher.encrypt(b"example", context=b"employee:123:phone")
original = cipher.decrypt(encrypted, context=b"employee:123:phone")
```

Неверный ключ, изменённые данные или несовпадающий контекст приводят
к `DecryptionError`; частичный открытый текст не возвращается.
Размер открытых данных ограничен 16 МиБ, контекста — 4096 байт.
Модуль работает в памяти и не предназначен для потоковой обработки больших файлов.

Перед внедрением нужно определить, что шифровать и кто получает доступ к ключу:
пароль пользователя с отдельной функцией получения ключа либо защищённое
хранилище ОС. Пароль нельзя передавать вместо ключа напрямую.
Хранение, резервирование и ротация ключей здесь не реализованы.
Потеря ключа означает потерю доступа к данным. Очистка секретов из памяти
в Python не гарантируется.

Этот модуль не обеспечивает прозрачное шифрование рабочей SQLite и WAL.
Шифрование базы целиком требует отдельного решения и согласования доступа
GUI для чтения и демона для записи. Копирование работающей БД без SQLite backup
не является корректной резервной копией. Миграции и автоматическое шифрование
файлов намеренно отсутствуют.

Документация используемого API:
https://cryptography.io/en/latest/hazmat/primitives/aead/
