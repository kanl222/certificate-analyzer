# Certificate Analyzer 0.2.6

## Изменения

- Комментарии к сотрудникам и сертификатам с сохранением в БД; обновление схемы до версии 6.
- Автоподбор сотрудников с различением однофамильцев по подразделению; сортировка сертификатов по сроку окончания действия.
- Полная защищённая резервная копия из меню «Файл → Экспорт», включая заявки, аудит, историю уведомлений и связанные файлы.
- Журнал результатов команд: восстановление ответа после обрыва связи, защита от повторного исполнения команды с тем же ID и проверка через «Служба → Результат операции».
- Проверка настроек через pydantic-settings и переменные окружения `CERTIFICATE_ANALYZER_*` с сохранением прежнего JSON-формата.
- Стандартные каталоги новых профилей через platformdirs; существующий `.certificate-analyzer` и `CERTIFICATE_ANALYZER_HOME` сохраняют приоритет.
- Каналы уведомлений Apprise и отдельное поле Rocket.Chat Incoming Webhook URL в настройках.
- Обновлена упаковка Windows/Linux с включением плагинов Apprise.

## Установка и обновление

Перед обновлением закройте GUI и сохраните резервную копию профиля. Установщик останавливает фоновый процесс перед заменой файлов. После установки запустите приложение заново.

Rocket.Chat: создайте Incoming Integration, задайте канал и пользователя отправителя, затем вставьте URL вида `https://сервер/hooks/id/token` в «Настройки → Уведомления». Сохраните настройки и перезапустите приложение и фоновый процесс. URL содержит секрет интеграции и хранится в файле настроек.

После аварии между изменением данных и сохранением ответа результат команды может оставаться неизвестным. Проверьте данные перед новой операцией; команда с прежним ID повторно не исполняется. Журнал результатов IPC не входит в архив переноса данных.

Полный автоматический прогон: 302 теста прошли, 49 пропущены; Ruff без ошибок.
GUI настроек и уведомлений проверен отдельно в ходе разработки. Реальная доставка
в Rocket.Chat требует URL вашей интеграции и не проверялась на внешнем сервере.
