# Certificate Analyzer 0.2.7

## Изменения

- **Сборка RPM для ALT Linux через Docker**:
  - Добавлены скрипты `packaging/linux/build-rpm-docker.ps1` (PowerShell) и `packaging/linux/build-rpm-docker.sh` (Bash) на базе официального образа `registry.altlinux.org/p10/alt:latest`.
  - Сборка внутри контейнера изолирована под непривилегированным пользователем `builder` (соответствует политике ALT Linux).
  - Настроены параметры RPM spec для ALT Linux (`%set_verify_elf_method no`, `%add_debuginfo_skiplist /*`) для корректной упаковки автономного бандла.
- **Интеграция и тестирование уведомлений в GUI**:
  - В форму «Настройки → Уведомления» добавлены кнопки асинхронного тестирования связи («Тест связи» для Rocket.Chat и «Тест каналов» для Apprise) без блокировки интерфейса.
  - Добавлен модуль `NotificationMessageBuilder` для единообразного форматирования уведомлений с указанием сетевого имени компьютера (`host_info`).
  - Дополнительная валидация и обработка ошибок отправки с отображением подробных сообщений.
- **Улучшения интерфейса и горячие клавиши**:
  - Индикатор состояния фонового мониторинга в статус-баре дополнен цветными маркерами активности (зелёный `●` при активной службе, красный `○` при остановленной).
  - Глобальные горячие клавиши: `Ctrl+F` для фокуса на поле поиска текущей вкладки и `Escape` для сброса поискового запроса.
  - Контекстные меню таблиц сертификатов и сотрудников дополнены быстрыми действиями копирования в буфер обмена (SHA-256 отпечаток, серийный номер, субъект, ФИО, должность).
- **Отказоустойчивость и безопасность Single Writer / IPC**:
  - Добавлены строгие аннотации типов во всех модулях рантайма (`ipc.py`, `operations.py`, `user_daemon.py`, `write_api.py`, `writer_lock.py`).
  - Улучшена обработка ошибок файловых блокировок и обрыва соединений с демоном.
  - Добавлены тесты отказоустойчивости и GUI в `tests/unit/test_resilience_hardening.py` и `tests/unit/test_gui_and_features.py`.

## Установка и обновление

Перед обновлением закройте GUI и сохраните резервную копию профиля. Установщик останавливает фоновый процесс перед заменой файлов. После установки запустите приложение заново.

## Файлы релиза

- `CertificateAnalyzer-0.2.7-Setup.exe` — Windows x64.
- `certificate-analyzer_0.2.7_amd64.deb` — Linux amd64.
- `certificate-analyzer-0.2.7-1.x86_64.rpm` — обычный профиль RPM.
- `certificate-analyzer-0.2.7-alt1.x86_64.rpm` — профиль пакета ALT Linux.
- `SHA256SUMS-0.2.7.txt` — контрольные суммы.
